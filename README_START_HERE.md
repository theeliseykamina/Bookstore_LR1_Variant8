## Что это

Консольная программа на **C++17**. В магазине можно хранить три типа товаров: обычные книги, учебники и канцелярские товары. Для каждого вида используются отдельные классы. Все экземпляры лежат в контейнере `Keeper`, основанном на динамическом массиве указателей `Base**`.

В реализации **нет STL-контейнеров (`vector`, `list`, `map`)**. Используются `new[]`, `delete[]`, `new`, `delete` и виртуальные функции.

## Самый простой запуск на Windows (рекомендую)

1. Скачай **Code::Blocks с MinGW** с официального сайта: https://www.codeblocks.org/downloads/binaries/ . Выбирай установщик, в названии которого присутствует **mingw** (важно: иначе может не быть компилятора).
2. Распакуй архив целиком, например в `C:\LR1_V8`. Не запускай файлы прямо внутри ZIP.
3. Открой Code::Blocks. В меню **File -> Open** выбери `Bookstore_LR1.cbp` из папки проекта.
4. В верхней панели проверь, что выбрано **Debug**, и нажми **F9 (Build and Run)**.
5. Появится консольное меню. Выбирай пункты цифрами, данные набирай в ответ на вопросы. Например, введи `1`, чтобы добавить обычную книгу.
6. Чтобы проверить сохранение, выбери **8**, впиши `bookstore.txt`; затем **9** и то же имя `bookstore.txt`. Если не получается найти файл, используй **полный путь**, например `C:\LR1_V8\bookstore.txt`.

**Важно:** все файлы `.h` и `.cpp` должны лежать в папке `src`, проект `.cbp` — рядом с ней. Интерфейс программы специально на простом английском, чтобы на Windows не было проблем с русской кодировкой. Русские названия и авторов вводить можно, но их отображение зависит от кодировки терминала.

Если Code::Blocks пишет `compiler not found`, вероятнее всего поставлена версия **без MinGW**. Установи сборку с MinGW или выбери установленный `GNU GCC Compiler` в Settings -> Compiler -> Toolchain executables.

## Что есть в меню

| Пункт | Действие |
|---|---|
| 1, 2, 3 | Добавить книгу, учебник или канцелярский товар |
| 4 | Посмотреть все товары |
| 5 | Посмотреть один товар по номеру |
| 6 | Изменить одно выбранное поле товара |
| 7 | Удалить товар |
| 8 | Сохранить магазин в текстовый файл |
| 9 | Загрузить магазин из текстового файла |
| 10 | Проверить копирующий конструктор и оператор присваивания |
| 0 | Завершить работу |

В квадратных скобках в консоли пишется, какие **конструкторы / деструкторы** вызываются. Это требование лабораторной.

## Структура проекта

- `src/Base.h`, `src/Base.cpp` — абстрактный базовый класс товара, общая цена, виртуальные методы.
- `src/Book.h`, `src/Book.cpp` — книга.
- `src/Textbook.h`, `src/Textbook.cpp` — учебник.
- `src/Stationery.h`, `src/Stationery.cpp` — канцелярия.
- `src/Keeper.h`, `src/Keeper.cpp` — собственный динамический контейнер указателей; добавление, удаление, копирование, файлы.
- `src/Input.h`, `src/Input.cpp` — простой безопасный ввод значений с клавиатуры.
- `src/main.cpp` — пользовательское меню.
- `Bookstore_LR1.cbp` — готовый проект Code::Blocks.
- `tests/` — файлы автоматической проверки. Вручную их редактировать не нужно.
- `ПОДГОТОВКА_К_ЗАЩИТЕ.md` — шпаргалка для защиты.
- `GITHUB_3_КОММИТА.md` — инструкция по обязательному GitHub.

## Компиляция без IDE (не обязательно)

Если уже установлен `g++`, из корневой папки проекта:

```bash
g++ -std=c++17 -Wall -Wextra src/*.cpp -o bookstore
./bookstore
```

На Windows можно собрать тот же проект в Code::Blocks, вручную эту команду вводить не требуется.

На Linux/macOS можно выполнить `sh tests/test_all.sh` для проверки.
